# BlockBreak

ブロックブラスト風のブロックパズルゲームです。ライブラリなしの HTML / CSS / JavaScript のみで動きます。

## あそびかた

1. 下のトレイに 3 つのピースが配られます。
2. ピースを 8×8 の盤面へドラッグして配置します（置ける位置ではマス目に吸着し、消えるラインが白くハイライトされます）。
3. 縦または横の 1 列が埋まると、その列が消えて得点になります。盤面が空になると「ALL CLEAR」の演出が出ます。
4. 3 つとも使い切ると次の 3 つが配られます。
5. トレイのどのピースも置けなくなったらゲームオーバーです。

## むずかしさ（Easy / Normal / Hard）

右上の ⚙ ボタンで設定画面を開くと、むずかしさを選べます。**変わるのは「そろえやすさ」に関わる 3 つだけ**です。

| | ぴったりピース | おたすけ | レベルが上がるライン |
| --- | --- | --- | --- |
| **Easy** | 100% | 100% | 15 本ごと |
| **Normal** | 70% | 40% | 10 本ごと |
| **Hard** | 50% | 0% | 6 本ごと |

- **ぴったりピース** … 自分でそろえかけた人へのごほうび（下の「3.」）
- **おたすけ** … 消せるピースが 1 つも無いときの救済（下の「4.」）
- レベルが上がるほど大きいピースが増えるので、**早く上がる Hard ほど、すぐむずかしくなります**

同じ AI に 200 ゲームずつ遊ばせたときの目安です。

| | 手数 | 消したライン | 3 連鎖できた割合 | 5 連鎖できた割合 |
| --- | --- | --- | --- | --- |
| Easy | 186 | 82 | 81% | 14% |
| Normal | 127 | 54 | 77% | 19% |
| Hard | 101 | 43 | 81% | 13% |

むずかしさを変えると、その場でさいしょからになります。**ハイスコアはむずかしさごとに別々に記録されます。**

## レベル

あそんでいると、だんだんむずかしくなります。ルールはこれだけです。

### 1. レベルはラインを消すと上がる

**きめられた本数のラインを消すごとに、レベルが 1 つ上がります。**（レベル 1 からはじまって、さいだいレベル 10）

何本ごとに上がるかは、むずかしさで変わります（Easy 15 本 / Normal 10 本 / Hard 6 本）。下の表は Normal の場合です。

画面の上のバーが、つぎのレベルまであと何本かを教えてくれます。

| 消したライン | 0〜9 | 10〜19 | 20〜29 | … | 90 本いじょう |
| --- | --- | --- | --- | --- | --- |
| レベル | 1 | 2 | 3 | … | 10 |

### 2. レベルが上がると、大きいピースが増える

ピースは大きさで 3 つのなかまに分けられます。

| なかま | 大きさ | 例 |
| --- | --- | --- |
| ちいさい | 1〜3 マス | ● / ●● / ●●● / L字 |
| ふつう | 4 マス | 四角 / 棒4 / T字 / S字 |
| おおきい | 5 マス いじょう | 棒5 / 大きいL / 2×3 / 3×3 |

**レベルが 1 つ上がるごとに、「ちいさい」が 4% へって、「おおきい」が 4% ふえます。「ふつう」はいつも 35% のままです。**

| レベル | ちいさい | ふつう | おおきい |
| --- | --- | --- | --- |
| 1 | 50% | 35% | 15% |
| 2 | 46% | 35% | 19% |
| 3 | 42% | 35% | 23% |
| 4 | 38% | 35% | 27% |
| 5 | 34% | 35% | 31% |
| 6 | 30% | 35% | 35% |
| 7 | 26% | 35% | 39% |
| 8 | 22% | 35% | 43% |
| 9 | 18% | 35% | 47% |
| 10 | 14% | 35% | 51% |

計算のしかた: `ちいさい = 50 −（レベル − 1）× 4`、`おおきい = 15 +（レベル − 1）× 4`

さいしょは小さいピースばかりなので、ラインをそろえやすいです。レベルが上がると大きいピースが多くなって、おく場所を考えないとすぐいっぱいになります。

なお、なかまの中でどのピースになるかは、レベルがちがってもかわりません。

### 3. あと少しでそろう列を 2 本つくると、ぴったりのピースが来る

**「あと 2〜3 マスで消える列」が 2 本いじょうあるとき、そのすき間にちょうど入る「ぼう」のピースが、さいだい 2 つまで配られます。**

- すき間は**ひとつづき**になっていること（とびとびはダメ）
- **1 マスのすき間はふくみません**（だれでも埋められるので）
- **2 本そろいかけていないと来ません**。1 本だけではごほうびになりません

これは「たまたま助かる」しくみではなく、**自分で 2 本そろえかけた人へのごほうび**です。2 本ぶんのぼうが来るので、うまくやれば **2 回つづけて消せて、コンボがのびます**。

来る確率はむずかしさで変わります（Easy 100% / Normal 70% / Hard 50%）。

### 4. 消せるピースが 1 つも無いときの「おたすけ」

配られた 3 つで**どうやってもラインが消せない**とき、1 つを消せるピースに差し替えます。こちらは行きづまったときの救済です。

Easy はいつも 100%、Normal は 40%、**Hard はありません（0%）**。

### 5. 全消しすると、ごほうびがある

盤面のブロックがぜんぶ消えると（全消し）、2 つのいいことがあります。

1. **ボーナス 300 点**
2. **ごほうびタイム** — つぎに配られる 3 つが、レベルにかんけいなく **ぜんぶ「ちいさい」ピース**になります

ピンチのときでも、全消しをねらえば立てなおせます。ごほうびタイムのあいだは、画面に 🎁 のマークが出ます。

## キーボード操作

マウスやタッチが使えなくても遊べます。

| キー | 動作 |
| --- | --- |
| Tab | サウンド → せってい → やり直す → ピース → 盤面 の順にフォーカス移動 |
| Enter / Space（ピース上） | そのピースを選ぶ |
| Enter / Space（盤面） | 未選択なら置けるピースを選ぶ。選択中ならカーソル位置に置く |
| 矢印キー | 盤面のカーソルを動かす |
| Escape | 選択を解除してトレイへ戻る（設定画面が開いていれば閉じる） |

盤面にフォーカスした状態で Enter を押し続けるだけでも進行できます（置ける位置が自動で選ばれ、配置後は次のピースが選択されます）。選択中のピースはトレイで黄色く囲まれ、盤面には着地プレビューとカーソルが表示されます。操作結果はスクリーンリーダー向けにも読み上げられます。

## ルール / スコア

| 項目 | 内容 |
| --- | --- |
| 盤面 | 8×8 |
| 配置 | 一度置いたピースは動かせない（回転もできない） |
| ライン消去 | 縦・横のどちらでも 1 列すべて埋まると消える |
| 配置点 | ピースのマス数ぶん加点 |
| 消去点 | 消したライン数 × 50 点 + コンボボーナス |
| コンボボーナス | 20 点から始まり、コンボが 1 つ増えるごとに +10 点（加算式） |
| コンボ | ライン消去が続くたびに 1 つ増える。ラインを消せない手を打つとリセット |
| 全消し | 盤面が空になると 300 点のボーナス。さらに次の 3 つが「ちいさい」ピースだけになる |
| レベル | 決められた本数のラインを消すごとに 1 つ上がる（最大 10）。上がるほど大きいピースが出やすくなる |
| むずかしさ | Easy / Normal / Hard。ぴったりピースとおたすけの確率、レベルの上がる速さが変わる |
| ハイスコア | むずかしさごとに分けて localStorage に保存 |

コンボは倍率ではなく加算です。まとめて 4 本消すより、1 本ずつ 4 回に分けてコンボを繋いだ方が高得点になります（220 点 対 340 点）。同時消しへの上乗せは置いていません。

### 配り方

1. **3 つとも置ける組み合わせを配る。** トレイは 3 つ使い切るまで補充されないので、置けないピースが混じると数手後に必ず詰みます。30 回まで引き直し、見つからないときは置ける数がいちばん多いものを使います。
2. **ぴったりピース。** 「あと 2〜3 マスで消える列」が 2 本以上あれば、そのすき間にちょうど入る棒を最大 2 つまで混ぜます（Easy 100% / Normal 70% / Hard 50%）。行どうしなら 1 本消しても他の行は崩れないので、連鎖を狙えます。
3. **おたすけ。** それでも「消せるピース」が 1 つも無いときだけ、1 つを差し替えます（Easy 100% / Normal 40% / Hard 0%）。

## 実行方法

静的ファイルだけなので `index.html` をブラウザで開くだけで動きます。ローカルサーバー経由で開く場合は次のとおりです。

```sh
npx http-server -p 8080
# http://localhost:8080 を開く
```

## バージョン

画面の右下に、いま動いている版が出ます。

```
v1.7.0 · b2501de · 2026-08-13 07:30 UTC
```

- `v1.7.0` … このリポジトリのバージョン（`index.html` の `app-version`）
- `b2501de` … 公開されているコミット。押すと GitHub のコミットページが開きます
- 時刻 … 公開ワークフローが動いた時刻（UTC）

ローカルで開いたときは `v1.7.0 · dev` と表示されます。コミットの情報は公開ワークフローが埋め込むためです。

同じ置換で `style.css?v=<SHA>` / `game.js?v=<SHA>` のように URL も変わるので、**更新したのに古い画面のまま、ということが起きません**。

## 実装メモ

- ピースは基本形 14 種を 90 度ずつ回転させ、重複を除いたものを抽選対象にしています。重みは基本形ごとの出現率になるよう、回転パターン数で割って配分しています。
- 操作は Pointer Events で実装しているため、マウスでもタッチでも同じコードで動きます。
- ドラッグ中のピースは指に隠れないよう少し上に浮かせて表示し、置ける位置ではマス目へ吸着します。
- 効果音は Web Audio API で合成しています。右上のボタンか設定画面でオン / オフを切り替えられ、設定は localStorage に残ります。

| 場面 | 音 |
| --- | --- |
| ピースを掴む / 選ぶ | 短く上がる音 |
| 置く場所が となりのマスへ動いた | 高く短いクリック音 |
| 置けない場所に来た | 低く鈍い音 |
| 盤面に置いた | 短い着地音（大きいピースほど低い） |
| 置かずに戻した / 選択を解除した | 下がる音 |
| ライン消去 | 消した本数ぶん音が積み上がる。連鎖が伸びるほど重なる音が高くなる |
| レベルアップ | 3 音の上昇 |
| 全消し | 5 音の上昇 |
| ゲームオーバー | 下降音 |

移動音はマスをまたいだ瞬間だけ鳴らし、さらに 30ms 以内の連続再生を間引いているので、速くドラッグしても音が潰れません。掴んだ直後の 1 回は掴む音と重なるため鳴らしません。
