# BlockBreak

ブロックブラスト風のブロックパズルゲームです。ライブラリなしの HTML / CSS / JavaScript のみで動きます。

## あそびかた

1. 下のトレイに 3 つのピースが配られます。
2. ピースを 8×8 の盤面へドラッグして配置します（置ける位置ではマス目に吸着し、消えるラインが白くハイライトされます）。
3. 縦または横の 1 列が埋まると、その列が消えて得点になります。
4. 3 つとも使い切ると次の 3 つが配られます。
5. トレイのどのピースも置けなくなったらゲームオーバーです。

## キーボード操作

マウスやタッチが使えなくても遊べます。

| キー | 動作 |
| --- | --- |
| Tab | サウンド → やり直す → ピース → 盤面 の順にフォーカス移動 |
| Enter / Space（ピース上） | そのピースを選ぶ |
| Enter / Space（盤面） | 未選択なら置けるピースを選ぶ。選択中ならカーソル位置に置く |
| 矢印キー | 盤面のカーソルを動かす |
| Escape | 選択を解除してトレイへ戻る |

盤面にフォーカスした状態で Enter を押し続けるだけでも進行できます（置ける位置が自動で選ばれ、配置後は次のピースが選択されます）。選択中のピースはトレイで黄色く囲まれ、盤面には着地プレビューとカーソルが表示されます。操作結果はスクリーンリーダー向けにも読み上げられます。

## ルール / スコア

| 項目 | 内容 |
| --- | --- |
| 盤面 | 8×8 |
| 配置 | 一度置いたピースは動かせない（回転もできない） |
| ライン消去 | 縦・横のどちらでも 1 列すべて埋まると消える |
| 配置点 | ピースのマス数ぶん加点 |
| 消去点 | (消したライン数 × 100 + 同時消しボーナス 50 × (ライン数 − 1)) × コンボ倍率 |
| コンボ | ライン消去が続くたびに倍率が 1 ずつ上昇。ラインを消せない手を打つとリセット |
| ハイスコア | ブラウザの localStorage に保存 |

理不尽な即死を減らすため、新しい 3 つを配るときは「1 つも置けない組み合わせ」を避けて抽選します。

## 実行方法

静的ファイルだけなので `index.html` をブラウザで開くだけで動きます。ローカルサーバー経由で開く場合は次のとおりです。

```sh
npx http-server -p 8080
# http://localhost:8080 を開く
```

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `style.css` | 見た目・アニメーション |
| `game.js` | ゲームロジック（ピース生成・配置判定・消去・スコア・ドラッグ操作） |

## 実装メモ

- ピースは基本形 14 種を 90 度ずつ回転させ、重複を除いたものを抽選対象にしています。重みは基本形ごとの出現率になるよう、回転パターン数で割って配分しています。
- 操作は Pointer Events で実装しているため、マウスでもタッチでも同じコードで動きます。
- ドラッグ中のピースは指に隠れないよう少し上に浮かせて表示し、置ける位置ではマス目へ吸着します。
- 効果音は Web Audio API による簡易ビープで、右上のボタンからオン / オフを切り替えられます。
